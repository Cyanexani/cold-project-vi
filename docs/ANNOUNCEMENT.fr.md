## Julia's Launcher 0.3.8 est sortie 🔧

**Correctif**
🇫🇷 **Le launcher est de nouveau entièrement en français** : l'étape Sécurité Windows ajoutée en 0.3.6 est traduite.

**Aussi depuis la 0.3.7**
🌈 Fini les textures arc-en-ciel sur les visages, les vêtements et les murs.
🪟 Windows 10 lance le jeu (D3D12 Agility SDK).
💾 Les fichiers de VIctory peuvent aller sur ton disque le plus rapide.

**Installation**
🔄 En 0.3.x : rien à faire, elle s'installe toute seule dans les 5 minutes, jeu fermé.
📥 Nouveau ou sur un ancien launcher : télécharge **VI-Setup-0.3.8.exe** sur https://github.com/felicienradio/cold-project-vi/releases/latest et lance-le.

Toujours bloqué ? Utilise **Aide > Envoyer les erreurs** dans le launcher et colle ton ID matériel sur Discord 💙
