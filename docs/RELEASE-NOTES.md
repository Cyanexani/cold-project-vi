Julia's Launcher 0.3.10: a save gallery, and bug reports in one click.

- Save gallery: share your save from Hardware & ID > Game saves > Share in the gallery (a title and a note). It shows on the public gallery page once the developers approve it; "Open the save gallery" lists everyone's. A downloaded save goes in with "Import a save..." (yours are backed up first). Only the game's save files are taken, checked at export and at import.
- Send errors: two buttons, no account needed. "Send" keeps the logs private and opens a public bug report on GitHub with the summary only (your PC's parts, versions, settings and what you wrote), which you can follow; "Send privately" skips the public report.
- Belobug's AMD engine: output at most 1080p (it ended with a fatal error at 1440p and 4K), and only offered on Radeon cards.
